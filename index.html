Sum of Two Numbers

Write a Java program that reads two integers and prints their sum.

Input Format

The first line contains an integer A. The second line contains an integer B.

Output Format

Print a single integer representing the sum of A and B.

Sample Input
12
8
Sample Output
20
Explanation

12 + 8 = 20, so the program displays 20.

Constraints
  • -10,000 ≤ A ≤ 10,000
  • -10,000 ≤ B ≤ 10,000
